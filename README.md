# Xiaomi Scale Sync

Локальное Android-приложение для приёма новых измерений с Xiaomi Mi Body
Composition Scale 2 (`XMTZC05HM`) по BLE, расчёта состава тела, хранения в
Room и записи поддерживаемых показателей в Health Connect.

Персональная сборка **не записывает напрямую в Huawei Health**. По актуальной
документации Huawei расширенная запись данных жировых весов требует enterprise-
аккаунта, а заявленная совместимость ограничена Android 6–13. Поэтому на vivo с
Android 16 такой маршрут нельзя считать поддерживаемым. Экспериментальный Huawei-
адаптер изолирован в отдельной конфигурации и не входит в персональный APK.

## Возможности

- принимает только стабильный пакет с весом и корректным импедансом;
- после первого полного взвешивания привязывается к MAC выбранных весов;
- отбрасывает пакеты от других устройств;
- хранит исходный пакет, MAC, время, вес, импеданс и версию алгоритма;
- локально рассчитывает BMI, жир, воду, мышцы, скелетные мышцы, кости, белок,
  висцеральный жир, BMR, метаболический возраст и безжировую массу;
- исключает повторы по детерминированному идентификатору из MAC, времени, веса и
  импеданса;
- доставляет записи через WorkManager и повторяет временные ошибки;
- поддерживает обычное фоновое BLE-сканирование через `PendingIntent` и режим
  повышенной надёжности с постоянным уведомлением;
- восстанавливает сканирование после перезагрузки, обновления приложения и
  повторного включения Bluetooth.

В Health Connect записываются типы, для которых существует подходящая модель:

| Локальное значение | Health Connect |
| --- | --- |
| Вес | `WeightRecord` |
| Процент жира | `BodyFatRecord` |
| Масса воды | `BodyWaterMassRecord` |
| Костная масса | `BoneMassRecord` |
| Безжировая масса | `LeanBodyMassRecord` |
| BMR | `BasalMetabolicRateRecord` |

Каждый тип получает собственный стабильный `clientRecordId` и метаданные
`Device.TYPE_SCALE`. Это делает повтор после сбоя между записью в Health Connect
и обновлением Room идемпотентным. Остальные рассчитанные значения остаются в
локальной базе, поскольку прямых эквивалентов для них в используемом API нет.

## Сборка

Требуются JDK 17 и Android SDK с Platform 36. Gradle Wrapper 8.13 входит в
репозиторий. Укажите SDK в `local.properties` (файл не коммитится):

```properties
sdk.dir=/path/to/Android/Sdk
```

Проверка и сборка персонального APK:

```bash
./gradlew testPersonalDebugUnitTest lintPersonalDebug assemblePersonalDebug
```

Результат:

```text
app/build/outputs/apk/personal/debug/app-personal-debug.apk
```

Установка через ADB:

```bash
adb install -r app/build/outputs/apk/personal/debug/app-personal-debug.apk
```

В рабочей копии можно держать JDK, Gradle и SDK в `.local-tooling/`; каталог
исключён из контроля версий. Сам проект не содержит абсолютных путей к этой
локальной установке.

## Первый запуск на vivo

1. Разрешите Bluetooth-сканирование и подключение. Разрешение уведомлений не
   блокирует обычное сканирование, но нужно для режима повышенной надёжности.
2. Сохраните рост, дату рождения и пол профиля.
3. Выдайте приложению запрошенные разрешения записи в Health Connect.
4. Нажмите «Найти весы», встаньте на `XMTZC05HM` босыми ногами и дождитесь
   финального измерения. MAC сохраняется только после стабильного пакета с
   допустимым импедансом.
5. В системных настройках vivo разрешите приложению автозапуск и фоновую
   активность, затем исключите его из оптимизации батареи. Названия пунктов могут
   различаться между версиями OriginOS/Funtouch OS.
6. Если обычный фон пропускает измерения, включите «Повышенную надёжность».

После принудительной остановки приложения Android не доставляет фоновые события
до следующего ручного запуска. Это системное ограничение. После обычной
перезагрузки регистрация восстанавливается автоматически, если производитель не
заблокировал автозапуск.

Чтобы заменить весы, снова нажмите «Найти весы». Старая привязка сохраняется до
получения корректного финального пакета от новых весов; при отмене поиска
автоматическое сканирование прежних весов возобновляется.

## Проверка на устройстве

Аппаратный критерий готовности требует реального vivo и не может быть выполнен
JVM-тестами. Для приёмки используйте следующий чек-лист:

- [ ] выполнить 10 последовательных взвешиваний без открытого Zepp Life;
- [ ] получить ровно 10 новых локальных записей без дублей;
- [ ] убедиться, что шесть поддерживаемых типов появились в Health Connect;
- [ ] повторить взвешивание с выключенным экраном;
- [ ] убрать приложение из списка недавних и повторить;
- [ ] перезагрузить телефон и повторить;
- [ ] выключить и снова включить Bluetooth;
- [ ] временно отозвать разрешения Health Connect, создать измерение, вернуть
  разрешения и проверить повторную доставку;
- [ ] проверить обычный фон и отдельно режим повышенной надёжности;
- [ ] подтвердить доставку в пределах двух минут при разрешённой фоновой работе.

Вес должен совпадать с дисплеем в пределах шага весов. Расчёт состава тела должен
быть воспроизводимым, но не обязан совпадать с закрытым алгоритмом Zepp Life.

## Huawei enterprise (только эксперимент)

Исходники адаптера находятся в source set `huaweiEnterprise`. Они не попадают в
`personal` и не должны использоваться как обещание совместимости. Собирать эту
конфигурацию имеет смысл только после получения enterprise appId, write-scope и
письменного подтверждения Huawei для целевого Android 16:

```bash
./gradlew -PHUAWEI_APP_ID=your_app_id assembleHuaweiEnterpriseDebug
```

Даже успешная компиляция проверяет лишь сигнатуры SDK, но не выдачу scope,
семантику единиц данных и отображение полей в Huawei Health. Без перечисленных
условий не следует подавать персональное приложение в AppGallery или включать
этот адаптер в релиз.

## Конфиденциальность и ограничения

Персональная сборка не использует сервер, аккаунт Xiaomi или Zepp Life и не
запрашивает доступ в интернет. Данные хранятся в приватной базе приложения;
резервное копирование Android отключено. Передача наружу выполняется только в
Health Connect после явного разрешения пользователя.

Первая версия рассчитана на одного пользователя, одни активные весы и только
новые измерения. История Zepp Life не импортируется.

Приложение не является медицинским изделием. Показатели состава тела — оценки по
формулам BIA для наблюдения за тенденциями. Не используйте их для диагностики,
лечения или самостоятельного изменения медицинских назначений.
