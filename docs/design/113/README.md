# Главный экран: дизайн v2 (#113)

Источник требований — [issue #113](https://github.com/ilguit/XiaomiScaleSync/issues/113) и его содержательные комментарии. Последнее утверждение владельца: [решение и нулевое количество питомцев](https://github.com/ilguit/XiaomiScaleSync/issues/113#issuecomment-5632878396). Более поздние уточнения имеют приоритет.

Пакет сохраняет согласованный дизайн для последующего технического планирования. Он не содержит реализации Compose и не означает выпуск изменения в APK.

- `specification.md` — итоговая Design specification, включая критерии приёмки и матрицу состояний.
- `prototype.html` — интерактивный HTML-фрагмент, демонстрирующий компоновку на вымышленных данных. Для просмотра в Codex используется inline visualization. Регуляторы ширины 412/320 и масштаба текста 1.0/2.0, типа измерения и наличия питомцев предоставляются средой просмотра.
- `verification.md` — выполненные проверки, ограничения и независимое ревью.

Макет не является реализацией графика Vico, Android-навигации, BLE, Health Connect, полного раскрытого набора метрик или системных жестов. Для них нормативны спецификация и существующие контракты приложения. Не переносить демонстрационные значения или заглушки маршрутов в продукт.

Исходная тема — `HuaweiTheme.kt` в main `5e4b980`. В текущей конфигурации нет productFlavors; старые упоминания personal/huaweiEnterprise описывают исторические сборки. Новая тёмная тема в scope не входит.

Снимки реального Pixel содержат пользовательские данные и намеренно не включены в пакет. Воспроизводимый результат аудита сохранён в issue без этих данных.
