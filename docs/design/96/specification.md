# Design specification: редактирование веса питомца (#96)

Статус: утверждено владельцем после независимого Design Review.

## Scope

Редактировать итоговый вес любой сохранённой записи питомца — ручной, SCALE или LEGACY. Сохранять происхождение, независимый постоянный признак последующего редактирования, исходные первое/второе взвешивания и неизменные id, petId, дату/время. История, график, tooltip, сравнение и дельты используют новый итоговый вес в прежней временной точке.

Не входят: изменение даты/времени, владельца или исходных взвешиваний; журнал версий, причина/заметка, восстановление прежнего значения; внешняя синхронизация питомцев; редактор человека.

## Технические указания для Planning

Если описания недостаточно, запланировать согласованное уточнение на Coding. ## Модель и термины

- `MANUAL` означает «Введено вручную» и остаётся происхождением записи.
- `isManuallyEdited` означает хотя бы одно явно сохранённое изменение итогового веса и не заменяет origin.
- SCALE/MANUAL/LEGACY сохраняют origin после редактирования. Возврат к исходному числу не снимает edited-флаг.
- Для SCALE/LEGACY первое и второе исходные взвешивания не меняются. Меняется только `petWeightKg`.
- Для MANUAL исходные взвешивания остаются отсутствующими и не фабрикуются.
- Полная история прежних итоговых значений не создаётся.
- Миграция и поддерживаемые backup/restore сохраняют origin, edited-флаг и исходные веса; старые записи получают edited=false.

## Вход и карточка

Текущая карточка измерения и компоновка сохраняются. Никакой новой плашки, текстовой панели действий или видимого маркера «Изменено вручную» не добавляется.

Непосредственно рядом с существующей кнопкой-корзинкой добавляется такой же по визуальному классу `HuaweiIconButton` с контурным карандашом. Доступное имя: «Изменить измерение {дата, время}, {вес}». Обе кнопки имеют touch target не менее 48 dp и помещаются на 320 dp/при увеличенном шрифте.

Существующий indicator «Введено вручную» из #92 не меняется и обозначает только MANUAL-origin.

    5 сентября 2026, 18:24                [✎] [⌫]
    4,125 кг   [существующий origin indicator]

## Экран редактора

Питомец → «Измерения» → карандаш → отдельный экран «Изменить вес» → успех возвращает к тому же питомцу, периоду и карточке.

    ‹  Изменить вес
       Барсик
       Вес, кг        [ 4,125 ]
       Дата и время   05.09.2026, 18:24
       Дата и время измерения не изменяются
       [ Сохранить ]

Имя и дата/время — неизменяемый контекст. Back закрывает простую форму без подтверждения и ничего не сохраняет. Повторное открытие загружает последнее сохранённое значение. Конфигурационная смена не теряет ввод; постоянный черновик не нужен.

## Валидация, precision и no-op

- Обязательный конечный положительный вес в кг, максимум 3 знака после точки/запятой; минимум 0,001 кг.
- Пустое, 0, отрицательное/нечисловое и лишняя точность не сохраняются. Диапазон весов 10–300 кг не применяется.
- Начальное поле использует тот же канонический formatter, что история после #92: максимум 3 знака, HALF_EVEN, без конечных нулей.
- Хранимое `4.1200000000000045` открывается как `4,12`; двоичная точность пользователю не раскрывается.
- No-op сравнивает каноническое отображение ввода и сохранённого веса. `4,12` и `4,120` эквивалентны: Save неактивен, точный Double не нормализуется, edited не ставится.
- Только явно отличающееся валидное значение сохраняется до 3 знаков и ставит edited=true.
- Открытие/закрытие не меняет запись. Историческое значение, не соответствующее новой валидации, можно заменить только новым валидным вводом.

## Сохранение и ошибки

- Saving блокирует повторное действие и показывает «Сохранение…».
- Успех атомарно меняет `petWeightKg` и edited-флаг, затем возвращает к карточке с новым весом.
- Ошибка: «Не удалось сохранить изменения. Попробуйте ещё раз»; ввод сохраняется, повтор доступен.
- Если питомец/измерение удалены: «Измерение недоступно. Вернитесь к измерениям»; сохранить нельзя, новая/чужая запись не меняется.
- Сеть, BLE и разрешения весов не нужны.
- Дубли других записей не требуют предупреждения: редактируется существующая запись.
- Удаление остаётся отдельным существующим подтверждаемым действием; в редакторе удаления и автосохранения нет.

## История и график

- После успеха история показывает новый вес до 3 знаков без конечных нулей. Нового edited-маркера нет.
- График, tooltip, эталонное сравнение и дельты используют новый итоговый вес.
- Новая точка не создаётся; порядок, период и определение последней записи не меняются.
- Редактирование старой записи не делает её последней.
- 0/1/несколько записей, одинаковые моменты/веса остаются корректны.

## Accessibility, размеры и flavors

- Экран: «Изменить вес питомца {имя}»; поле имеет label «Вес, кг» и decimal keyboard.
- Дата читается как «Дата и время измерения: … Не изменяется».
- Field/save errors — polite live region; saving объявляется screen reader.
- После ошибки фокус остаётся в форме; после успеха возвращается к изменённой карточке.
- Вертикальный scroll сохраняет смысл при клавиатуре, длинном имени и максимальном шрифте.
- Проверить normal/320 dp, темы, screen reader, personal/huaweiEnterprise. Personal не получает Huawei-зависимостей; внешняя синхронизация не меняется.

## Матрица состояний

| Поверхность | Normal/empty | Loading/unavailable/error |
|---|---|---|
| История | Карандаш рядом с корзиной у каждой загруженной записи | При 0 записей edit отсутствует; loading/error не дают ложного действия |
| Редактор | Текущий вес, имя, read-only дата | Saving, field error, save error, удалённая запись/питомец |
| История/график | Новый вес в прежней точке | Неуспешный save ничего не меняет |
| Origin/edited | Origin не меняется; edited хранится без новой плашки | LEGACY остаётся LEGACY; edited не подменяет origin |
| Удаление | Существующее подтверждение | Delete error отдельно от save error |

## Критерии приёмки

1. У карточки рядом с текущей корзиной есть доступный карандаш; компоновка и empty/loading/error сохранены.
2. Редактор показывает верного питомца, текущий итоговый вес и неизменяемые дату/время; Back ничего не меняет.
3. Валидны 0,001/4,125/целые и точка/запятая; невалидны пустое/0/отрицательное/нечисло/лишняя точность; hardware-range отсутствует.
4. Canonical no-op, эквивалентный текст, открытие/закрытие и повторное нажатие при saving не меняют запись/edited.
5. Успех меняет только итоговый вес выбранной записи и ставит edited=true; id/petId/date/time/исходные веса сохраняются.
6. SCALE/MANUAL/LEGACY сохраняют origin; existing MANUAL-indicator не меняется; новая плашка edited не появляется.
7. История, tooltip, сравнение и дельты используют новый вес с форматированием #92; время/порядок/период/last не меняются.
8. Save error сохраняет ввод; удалённый объект не создаёт/не меняет чужие данные; offline/BLE/permissions не блокируют.
9. Delete flow сохранён отдельно; дубли других записей не требуют предупреждения.
10. Пройдены width/font/keyboard/accessibility/theme/flavor checks; migration и backup/restore сохраняют origin, edited и исходные веса.
