# Инструкция для модератора

Weigh Together 1.0 — локальный дневник веса людей и питомцев с дополнительным подключением Xiaomi Mi Body Composition Scale 2 (XMTZC05HM). Логин, пароль, SMS, подписка и тестовый аккаунт не требуются. Для ручного сценария физические весы и Health Connect не нужны. Устройство должно поддерживать Android 8.0+ и Bluetooth LE (аппаратная возможность заявлена обязательной в manifest).

## Проверка без весов

1. Запустите приложение. Создайте профиль человека, например «Иван Плюшкин», заполните рост, пол и дату рождения вымышленными данными. Настройку весов и Health Connect можно оставить невыполненной.
2. Откройте историю этого человека, нажмите «+», введите вес, например 78,4 кг, и прошедшую дату/время. Сохраните. Добавьте ещё 2–3 записи с разными прошедшими датами и весом.
3. Убедитесь, что записи отображаются в истории и на графике веса. Выберите другой период. Ручные записи имеют признак ручного ввода; состав тела по одному весу не создаётся.
4. Откройте запись, измените вес и сохраните. Проверьте изменение в истории. Удалите одну тестовую запись с подтверждением.
5. В управлении профилями создайте питомца — кошку «Барон Батон». В его профиле нажмите «+» рядом с «Измерения», введите, например, 4,8 кг с прошедшей датой. Добавьте другие даты и откройте график питомца.
6. Закройте и снова откройте приложение: сохранённые профили и записи остаются. В настройках можно экспортировать JSON резервной копии через системный выбор файла. Используйте только тестовые данные: файл содержит чувствительные сведения и не шифруется приложением.

Будущие даты запрещены. Повтор записи с тем же весом и минутой требует дополнительного подтверждения. Не используйте реальные данные для проверки импорта в режиме полной замены: этот режим заменяет локальные данные.

## Дополнительные функции

- **Весы:** включите Bluetooth, выдайте запрошенные разрешения, выберите XMTZC05HM в настройках, встаньте босиком и дождитесь завершения измерения. Проверка реальной BLE-передачи требует весов; ручной ввод её не подтверждает. На Android 11 и старше для BLE может потребоваться геолокация.
- **Health Connect:** на совместимом устройстве подключите его в настройках и разрешите запись показателей основного профиля. Интеграция необязательна. Удаление локальной записи не удаляет уже отправленную копию из Health Connect.
- **Напоминания:** создайте расписание в профиле и разрешите уведомления. Для режима будильника нужны специальные системные разрешения (точные будильники, полноэкранное уведомление); звук работает через foreground service. Не выдавайте эти разрешения для проверки одного ручного ввода.
- **Фоновое получение веса:** режим повышенной надёжности поддерживает BLE-сканирование через foreground service с постоянным уведомлением. Он не используется для скрытой сетевой передачи.

Справочные значения и расчёты не являются диагнозом. Приложение не предназначено для лечения.
