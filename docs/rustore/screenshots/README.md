## Требования и проверка

По [правилам RuStore](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication), проверенным 2026-10-06: минимум 3 мобильных скриншота; PNG/JPEG; каждый до 3 МБ; размер не более 2160×3840 пикселей; рекомендуемое соотношение 16:9 (для портретной ориентации — 9:16). Не растягивать интерфейс ради рекомендации: сохранять пропорции Pixel. Проверить принятие фактического соотношения в консоли.

Снимки должны показывать реальный UI текущей версии на Pixel, русский язык, только вымышленные профили/данные. Допустим лёгкий юмор в именах, без насмешек над весом и здоровьем. Не включать отладочные панели, диалоги разрешений, клавиатуру поверх основного содержимого, личные уведомления, имена владельца или сведения о выбранном реальном BLE-устройстве.

Перед загрузкой открыть каждый снимок в полном размере: проверить обрезку текста, читаемость, отсутствие персональных данных и соответствие описанию приложения. Ручные измерения не выдавать за результаты реальной BLE-проверки. Заполнение демонстрационных данных не должно уничтожать существующие пользовательские данные устройства.
