# Скриншоты для RuStore

Пять реальных снимков приложения сняты и визуально проверены 2026-10-06 на **Google Pixel 7 Pro, Android 16**, версия **0.4 (275)**, debug APK из commit `bffb8904`. UI и данные сняты с устройства, изображения не ретушировались и не генерировались.

Снимки подготовлены для карточки версии **1.0**. Историческая версия съёмки — **0.4 (275)**: показанные экраны измерений, состава тела, графиков и профилей в 1.0 не изменились. Новый экран политики конфиденциальности в эту серию не входит.

Все PNG имеют разрешение **1080×1920**, портретное соотношение **9:16**, каждый меньше 3 МБ. На время съёмки использован Android display override 1080×1920 / 360 dpi; исходные 1440×3120 / 560 dpi восстановлены после съёмки. Это изменение размера рендеринга приложения на устройстве, без растяжения снимков.

## Демонстрационные данные

Лев Приседалов, Анна Балансова, кот Батон и пёс Бублик полностью вымышлены. 120 записей людей и 40 записей питомцев импортированы штатным механизмом JSON в отдельный временный Android-профиль. Основной профиль и его данные не очищались. Все записи людей имеют `USER_LOCAL` / `LOCAL_ONLY`, Health Connect и доступ к BLE не предоставлялись. После съёмки телефон возвращён в основной профиль, временный профиль удалён.

[demo-data.json](demo-data.json) — воспроизводимый синтетический набор в поддерживаемой схеме backup v8. Он не содержит реальных измерений или идентификаторов весов. Значения состава тела заданы для демонстрации интерфейса, а не получены с весов; algorithmVersion явно помечен `synthetic-demo-not-a-measurement`. Не использовать для медицинских выводов или проверки точности алгоритмов. Импортировать только в пустой демонстрационный профиль, без Health Connect. JSON не входит в APK и не добавляет demo-режим пользователям.

## Проверки

Просмотрены все пять изображений: русский интерфейс, реальные компоненты приложения, без персональных данных, клавиатуры, диалогов разрешений и сведений о реальных весах. Системные значки в статус-баре не содержат текст уведомлений. Скриншоты подтверждают импорт и отображение данных, но не проверяют радиоприём BLE, отправку в Health Connect или работу напоминаний.

Снимки сделаны на debug-сборке с тем же production UI; после получения постоянного ключа остаётся smoke-проверка финального подписанного APK. Если его UI изменится, кадры нужно переснять.

[Требования RuStore](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication): минимум три мобильных снимка, PNG/JPEG, до 3 МБ, не более 2160×3840. Перед отправкой проверить предпросмотр карточки в консоли.
