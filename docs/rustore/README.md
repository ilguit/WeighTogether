# Пакет публикации Weigh Together в RuStore

Материалы подготовлены для версии **0.4**, package `com.palixander.weightogether`, Android 8.0+ (minSdk 26). Это пакет для подготовки карточки и модерации, а не подтверждение состоявшейся публикации.

## Содержимое

- Название: `Weigh Together` (14 символов, лимит 30).
- [Краткое описание](short-description-ru.txt) — отдельное поле карточки, лимит 80 символов.
- [Полное описание](full-description-ru.txt) — отдельное поле карточки, лимит 4000 символов.
- [Иконка 512×512](assets/icon-512.png) — PNG с непрозрачным фоном, из текущего Android vector; [воспроизводимый экспорт](assets/render-icon.py).
- [Скриншоты и требования](screenshots/README.md).
- [Факты о данных и разрешениях](privacy-and-permissions.md) — основа декларации, не утверждённая публичная политика.
- [Сценарий модератора](moderation-ru.md), включая работу без весов.
- [Подпись и сборка APK](signing.md).

Предлагаемая категория: «Здоровье и фитнес» (сверить доступное название в консоли). Возрастной рейтинг определить по анкете RuStore; приложение не заявляет медицинские функции. Реклама, покупки и обязательная регистрация в текущей реализации отсутствуют.

## Чеклист перед отправкой

- [ ] Владелец утвердил политику конфиденциальности с данными оператора и опубликовал её по доступному HTTPS URL; ссылка внесена в консоль.
- [ ] Есть постоянный ключ подписи владельца вне Git; подтверждены alias и резервная копия. Временный/debug-ключ не используется.
- [ ] Собран финальный release APK по signing.md, versionCode увеличен и закоммичен, versionName остался 0.4. Проверены package, сертификат, подпись и установка.

## Остающиеся внешние блокеры

На момент подготовки материалов нет подтверждённых аккаунта RuStore, контакта поддержки, публичного URL утверждённой политики и постоянного production-ключа. Их нельзя заменить вымышленными реквизитами или тестовой подписью. Доступность финального подписанного APK и фактические результаты device QA должны быть подтверждены после их получения. Состояние скриншотов ведётся отдельно в их манифесте.
