# Пакет публикации Weigh Together в RuStore

Материалы подготовлены для версии **0.4**, package `com.palixander.weightogether`, Android 8.0+ (minSdk 26). Это пакет для подготовки карточки и модерации, а не подтверждение состоявшейся публикации.

## Содержимое

- Название: `Weigh Together` (14 символов, лимит 30).
- [Краткое описание](short-description-ru.txt) — отдельное поле карточки, лимит 80 символов.
- [Полное описание](full-description-ru.txt) — отдельное поле карточки, лимит 4000 символов.
- [Иконка 512×512](assets/icon-512.png) — PNG с непрозрачным фоном, из текущего Android vector; [воспроизводимый экспорт](assets/render-icon.py).
- [Скриншоты и требования](screenshots/README.md).
- [Политика конфиденциальности](privacy-policy.html) — HTML для публичного размещения, с тем же текстом, что доступен offline в приложении.
- [Факты о данных и разрешениях](privacy-and-permissions.md) — основа декларации магазина.
- [Сценарий модератора](moderation-ru.md), включая работу без весов.
- [Подпись и сборка APK](signing.md).

Предлагаемая категория: «Здоровье и фитнес» (сверить доступное название в консоли). Возрастной рейтинг определить по анкете RuStore; приложение не заявляет медицинские функции. Реклама, покупки и обязательная регистрация в текущей реализации отсутствуют.

## Единый текст политики

Канонический текст — `app/src/main/res/raw/privacy_policy_ru.txt`. Он включён в APK и открывается из «Настройки → Данные и приложение → Политика конфиденциальности», а также по системным запросам Health Connect. Экран не требует интернета и не запускает основной экран или запрос Bluetooth-разрешений.

После правки текста выполните `python3 docs/rustore/render-privacy-policy.py`. Перед публикацией проверяйте `python3 docs/rustore/render-privacy-policy.py --check`: HTML должен в точности соответствовать тексту APK. HTML не содержит внешних ресурсов, трекеров или JavaScript. Текст политики русский; название, пояснение пункта настроек и кнопка возврата переведены на все языки интерфейса (русский, английский, немецкий, французский, итальянский, украинский, белорусский, японский и китайский). Публичный URL нужно получить после размещения HTML на доступном без авторизации HTTPS-хостинге и внести в консоль RuStore.
